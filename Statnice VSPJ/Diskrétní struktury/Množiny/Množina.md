**Množina** je soubor prvků, které se neopakují a je možné jednoznačně určit, jestli do množiny patří nebo ne.
**Podmnožina** je část množiny - Větší množina ji obsahuje.
Množinu zapisujeme jako:
- Výčtem prvků: `A = {1,2,3,4}`
- Charakteristikou: `A = {x ∊ N; 1 < x < 500}` - všechna celá čísla mezi 1 a 500. Definuje jí **charakteristická funkce**
**Potenční množina** je množina všech množin, které může daná množina obsahovat.
**Universum**: Největší možná množina co uvažujeme. Obsahuje všechno s čím chceme něco dělat.
# Operace s množinami
- Sjednocení: Všechny prvky obou množin
- Průnik: Společné prvky
- Doplněk množiny A: Všechno z universa, co není v množině A 
- Rozdíl A - B: Z množiny A odeberu prvky množiny B
```
	A =     {1,2,3,4}
	B =     {2,4,5}
	A - B = {1,3}
```
- Kartézský součin: Množina uspořádaných dvojic (první prvek z první množiny, druhý prvek z druhé množinu)
	- Kartézský součin konečné a nekonečné množiny je **přímka**, nekonečné x nekonečné je obsah
```
	A =     {1,2,3,4}
	B =     {2,4,5}
	A x B = {(1, 2), (1, 4), (1, 5), ..., (4, 4), (4, 5)}
```  
# Vlastnosti množin
**Mohutnost množiny**: Nástroj pro porovnání velikosti množin. U konečných množin je to součet jejich prvků. U nekonečných jsou buď:
- spočetné - prvky jdou spárovat beze zbytku
- nespočetné - nejde je spočítat
