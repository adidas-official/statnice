Podniková architektura se rozděluje do 3 vrstev:
# Podniková vrstva
- Popisuje fungování a strukturu organizace: Strategie a cíle, jaké oddělení v organizaci jsou, kdo jim velí, hierarchické uspořádání
- Aktéry a klíčové procesy, které generují organizaci zisk
# Aplikační vrstva
- Software pro vnitřní podporu chodu organizace. Je to veškerý software, který je potřeba pro management, účetní systémy, vývojové programy a nástroje, atd.
# Technologická vrstva
- Veškerý hardware a software pro hladký chod aplikací: Sítě a segmentace, systémový software (OS, Uložiště ,. ..)
